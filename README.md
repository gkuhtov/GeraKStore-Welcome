# GeraKStore Welcome

Приветственный экран перед запуском приложения. Потому что «Продолжить» можно нажать и красиво.

GeraKStore Welcome собирает атмосферные welcome-интерфейсы для iOS-приложений.

## Варианты

### 🌌 WelcomeToSpace

Тёмная космическая атмосфера, мягкое свечение и современный интерфейс.

### 🌸 WelcomeToJapan

Сакура, волна, дерево и немного Японии перед запуском приложения. Почему? Просто красиво.

## Что умеет

- ✨ Анимации и декоративные элементы
- 🍎 Интерфейс в духе iOS
- 🌸 Разные визуальные стили
- 🔗 Telegram и GitHub
- ⚙️ Настройка текста и внешнего вида
- 👋 Возможность скрыть welcome-экран

## Связь с экосистемой

- [GeraKStore](https://github.com/gkuhtov/GeraKStore) - основной каталог
- [GeraKStore-Manager](https://github.com/gkuhtov/GeraKStore-Manager) - управление каталогом
- [GeraKStore-Web](https://github.com/gkuhtov/GeraKStore-Web) - веб-версия
