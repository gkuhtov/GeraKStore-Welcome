## ✨ Welcome

GeraKStore Welcome собирает красивые приветственные экраны для iOS-приложений.

Первое впечатление становится частью общей атмосферы GeraKStore.

### 🌌 WelcomeToSpace

Тёмная космическая атмосфера, мягкое свечение и современный Liquid Glass.

### 🌸 WelcomeToJapan

Сакура, волна, дерево и немного Японии перед запуском приложения. Почему? Просто красиво.
